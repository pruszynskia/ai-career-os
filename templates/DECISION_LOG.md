# Decision Log

A running log of smaller decisions that don't warrant a full ADR (see
`templates/ADR.md` for architecturally significant ones). One row per
decision, newest first.

| Date           | Decision             | Reason  | Made by |
| -------------- | -------------------- | ------- | ------- |
| `<YYYY-MM-DD>` | `<what was decided>` | `<why>` | `<who>` |

## When to use this vs. an ADR

- **Decision Log**: reversible, low-blast-radius choices (a naming
  convention, a library version pin, a UI copy decision).
- **ADR** (`memory-bank/decisions.md`): architecture, data model, or
  dependency choices that are expensive to reverse later.
